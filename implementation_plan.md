# Samarth — AI-Guided Physiotherapy Rehabilitation Platform — Architecture Plan

## Background

Your **PS1 (Computer Vision) module** — *KinemaFlow Pipeline* — is a fully working batch-processing system that performs:
- Adaptive video quality enhancement (contrast, brightness, noise, blur correction)
- IS-Net background segmentation with MediaPipe fallback
- 2D pose estimation via MediaPipe PoseLandmarker (33 landmarks)
- Joint angle computation for hip / knee / ankle (left + right sides)
- Temporal smoothing via Savitzky-Golay filter
- Repetition detection via flexion peak analysis
- Bilateral symmetry analysis (Pearson correlation + ROM ratio)
- CSV export and interactive HTML dashboard generation

The platform will wrap PS1 behind a strict service API adapter and build the full rehabilitation portal around it — **without modifying any PS1 internals**.

### 3. Backend Architecture

#### [MODIFY] Backend: `backend/` (all new files)

**FastAPI app** (`backend/main.py`) registers:
- All route prefixes under `/api/v1/`
- WebSocket endpoints at `/ws/session/{session_id}` and `/ws/camera/{token}`
- Swagger UI at `/docs`
- CORS for frontend origin

**PS1 Adapter Service** (`backend/services/pose_engine/adapter.py`)

This is the core integration layer. It wraps PS1 without modifying it:

```python
# The adapter imports PS1 by adding pipeline/ to sys.path
# It NEVER modifies PS1 files
# All external code uses PoseEngineAdapter — never PS1 directly

class PoseEngineAdapter:
    def process_video(self, video_path: str, session_id: str) -> PoseEngineResult
    def process_frame_realtime(self, frame_bytes: bytes, timestamp_ms: int) -> FrameResult
    def validate_camera_position(self, frame_bytes: bytes) -> ValidationResult
    def get_status(self) -> EngineStatus
```

**Camera Validation Logic** uses PS1's `PoseEstimator.extract_joint_coordinates()` to check:
- Visibility thresholds for each of the 6 required landmarks
- Bounding box check to verify user is within the exercise zone
- Frame brightness check for lighting validation
- Frame-to-frame stability check for camera stability

**Model plug-in interface** (`base_analyzer.py`):
```python
class BaseExerciseAnalyzer(ABC):
    @abstractmethod
    def analyze_rep(self, angle_data: dict, rep_id: int) -> PS2RepResult:
        """Analyze a single rep. Return exact PS2 schema."""

    @abstractmethod  
    def analyze_session(self, session_angle_data: dict) -> PS2SessionResult:
        """Analyze full session. Return session score + quality trend."""

    @abstractmethod
    def load_model(self, model_path: str) -> None:
        """Load trained model weights. Called once at startup."""
```

**To plug in the real PS2 model (when ready):**
```python
# model_analyzer.py (your teammate fills this in)
class ModelExerciseAnalyzer(BaseExerciseAnalyzer):
    def load_model(self, model_path: str):
        self.model = torch.load(model_path)   # or ONNX, sklearn, etc.
    
    def analyze_rep(self, angle_data, rep_id):
        # Run inference — return same PS2RepResult schema
        prediction = self.model.predict(angle_data)
        return PS2RepResult(
            rep_id=rep_id,
            error_flags=prediction.flags,
            confidence=prediction.confidence,
            ...
        )

# In config.py:
PS2_MODEL_PATH = os.getenv('PS2_MODEL_PATH', '')  # Set env var when ready
PS2_USE_REAL_MODEL = bool(PS2_MODEL_PATH)          # Auto-switch
```
